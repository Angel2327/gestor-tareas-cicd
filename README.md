# gestor-tareas-cicd

Proyecto final de **Integración y Entrega Continua de Software** (EAFIT, 2026-2).

Gestor de tareas con 3 componentes:

| Componente | Tecnología                                | Responsabilidad                      |
| ---------- | ----------------------------------------- | ------------------------------------ |
| Frontend   | HTML/JS/CSS servidos por Nginx (sin root) | Interfaz de usuario                  |
| Backend    | Python 3.13, FastAPI, SQLAlchemy, Alembic | API REST, reglas de negocio, migraciones |
| Base datos | PostgreSQL 17                             | Persistencia                         |
